# 검증 체크리스트

모드별로 출력 직전에 통과시킨다. 하나라도 미통과면 발행하지 않는다.

---

## 공통 (전 모드)

### 사실 검증
- [ ] 조회 기준 시각(KST)을 확정했고 참고사항에 적었는가
- [ ] 본문의 **모든 숫자**에 출처가 있는가 (순위·전적·xG·부상·배당)
- [ ] 검색으로 확인하지 않고 기억으로 쓴 숫자가 하나라도 있는가 → 있으면 삭제하거나 검색한다
- [ ] 유저 자료와 검색 결과가 충돌하는 항목을 '충돌/불확실'로 명시했는가
- [ ] 예상 라인업과 공식 라인업을 구분해 적었는가
- [ ] 소문·루머를 사실처럼 쓰지 않았는가

### 근거 태깅 (v2 신설)
본문에 쓰는 사실 주장은 내부적으로 다음 형태를 갖춘다. 태그가 없으면 문장을 뺀다.

```
주장 [출처명 / 조회 YYYY-MM-DD HH:MM KST]
```

발행문에는 태그를 노출하지 않되, 참고사항 섹션에 **출처 목록과 조회 시각**을 남긴다.

### 형식
- [ ] 반말 종결형으로 통일했는가
- [ ] 본문에 '이미지'라는 단어를 쓰지 않았는가
- [ ] 제목에 '분석·예측·승부·배당'을 쓰지 않았는가
- [ ] 제목 앞 15자 안에 핵심 키워드가 있는가
- [ ] 내부 링크 3개, 해시태그 15개가 있는가
- [ ] 템플릿 바깥의 섹션을 새로 만들지 않았는가
- [ ] 해외 경기는 KST와 현지 시각을 병기했는가

### 체력 부하 (전 모드 필수)
- [ ] 핵심 선수별 직전 경기 출전 분수를 **검색으로** 확인했는가
- [ ] 경기 간격(일수)을 계산했는가. 3일 이하인가
- [ ] 미드위크 대항전·컵대회 출전 및 이동 거리를 확인했는가
- [ ] A매치 차출 복귀자(특히 대륙 간 이동)를 확인했는가
- [ ] 경고 누적 및 다음 경기 결장 확정자를 확인했는가
- [ ] 벤치 뎁스(60~75분 교체 자원)를 확인했는가
- [ ] 확인 불가 항목을 참고사항에 명시했는가

## 모드 A 추가 (프리뷰)

### 확률
- [ ] `tools/devig.py`로 Shin 디빅을 돌렸는가 (손계산 금지)
- [ ] `tools/poisson.py`로 모델확률을 만들었는가 (감으로 정한 숫자 금지)
- [ ] λ가 0.4~3.5 범위인가
- [ ] λ 정성조정 총량이 팀당 ±0.45 이내인가
- [ ] 정보 등급(A/B/C/D)을 판정했고, 그에 맞는 w와 이탈 상한을 적용했는가
- [ ] 홈승+무+원정승 = 100.0%인가
- [ ] 2-way 합 = 100.0%인가
- [ ] 무승부 확률이 리그 베이스레이트 ±6%p 이내인가
- [ ] 무승부가 18% 미만이거나 34% 초과가 아닌가
- [ ] 아시안핸디 정푼 라인의 푸시 확률(2% 이상)을 표기했는가
- [ ] EH와 AH를 섞어 쓰지 않았고 어느 쪽인지 명시했는가
- [ ] 오버라운드 7% 초과 배당판을 기준으로 삼지 않았는가

### 픽
- [ ] 픽 티어가 정보 등급이 허용하는 범위인가 (D등급 → 무조건 PASS)
- [ ] 주력 픽 금지 조건 5개 중 걸리는 것이 없는가
- [ ] 주력은 경기당 1개, 하루 1개인가
- [ ] **반대 픽의 근거 2개**를 실제로 적어보고 검토했는가
- [ ] 소스 문서의 픽을 임의로 바꾸지 않았는가 (변경 시 사유를 참고사항에 명시)
- [ ] 파생 마켓(코너·카드·득점자)을 주력으로 쓰지 않았는가

### 모순
- [ ] 본문 논거가 '오버'인데 픽이 '언더'로 나가지 않는가
- [ ] 전술 매치업 결론과 최종 선택이 연결되는가
- [ ] '시장의 냄새'에서 지적한 함정을 최종 픽이 회피했는가
- [ ] 부상·출전정지·로테이션 변수가 λ에 실제로 반영됐는가

### 기록
- [ ] `logs/picks.csv`에 한 줄 추가했는가 (**PASS도 기록**)
- [ ] 킥오프 직후 `closing_odds`를 채울 일정을 잡았는가

## 주기 점검 (20건마다)

```bash
python3 tools/calibrate.py logs/picks.csv --split
```

- [ ] CLV 평균이 양수인가 → 음수면 픽 논리를 손본다
- [ ] 캘리브레이션 구간에서 '과신'이 반복되는가 → w(시장가중치)를 0.05 올린다
- [ ] 특정 마켓·리그에서만 나쁜가 → 그 마켓을 한동안 PASS 처리한다
- [ ] Brier가 0.25를 넘는가 (표본 30건 이상일 때만 해석) → λ 조립 절차를 재점검한다
