# 리그별 베이스레이트 (시드값)

> **경고 — 이 표는 시드값이다.**
> 아래 숫자는 최근 시즌들의 장기 평균에 대한 **근사치**이고, 소수점 단위 정밀도가 없다.
> 그대로 인용해 본문에 "이 리그 무승부 비율은 정확히 24.3%다"라고 쓰면 안 된다.
> 시즌마다 `tools/baserate.py`로 실제 결과 데이터에서 다시 뽑아 이 파일을 덮어써라.
>
> ```bash
> python3 tools/baserate.py results_2025_26.csv --by league
> ```
>
> 원본 데이터는 football-data.co.uk(무료 CSV) 또는 FBref에서 받는다.
> **마지막 갱신: (미갱신 — 시드값 상태)**

---

## 1. 용도

이 표는 두 가지 용도로만 쓴다.

1. **λ 조립의 기준값** — `리그평균홈득점`, `리그평균원정득점` 열
2. **무승부 확률 검산** — 최종 무승부 확률이 이 리그의 무승부 비율에서 ±6%p 이상
   벗어나면 계산을 다시 본다

**본문에 이 숫자를 사실로 인용하지 않는다.** 인용하려면 검색으로 실제 값을 확인하고
출처와 조회 시각을 붙인다.

### 표를 쓸 때 반드시 기억할 것

- **홈 어드밴티지는 2020년 이후 전반적으로 축소됐다.** 오래된 감각(홈승 48~50%)으로
  보정하면 홈팀 확률을 체계적으로 과대평가한다.
- **K리그는 무승부 비율이 유럽 5대 리그보다 높다.** K리그2는 특히 그렇다.
  유럽 감각으로 무승부를 24%쯤 잡으면 K리그에서는 구조적으로 틀린다.
- **분데스리가는 득점이 많다.** 언오버 기준점 판단에서 다른 리그와 같이 취급하면 안 된다.
- **UCL 조별리그는 전력 격차가 커서 1X2 분포가 왜곡된다.** 리그 평균을 그대로 쓰지 말고
  팀별 지수에 더 의존한다.
- 컵대회(FA컵·코리아컵)는 로테이션 폭이 커서 **베이스레이트 자체를 신뢰하지 않는다.**
  정보 등급 D 처리 대상이다.

## 3. 갱신 절차

### 3-1. 어디서 받나

**football-data.co.uk** — 회원가입도 API 키도 없이 CSV를 그냥 준다. 이것으로 충분하다.
득점·슈팅·카드·배당이 들어 있다. **단 xG는 없다.**

경로가 두 종류다.

| 대상 | 경로 | 특징 |
|---|---|---|
| 유럽 주요 리그 | `/mmz4281/{시즌}/{코드}.csv` | 시즌당 파일 1개 |
| 그 외 국가(K리그 포함) | `/new/{국가코드}.csv` | **한 파일에 전 시즌** |

리그 코드: `E0` EPL / `SP1` 라리가 / `D1` 분데스리가 / `I1` 세리에A / `F1` 리그앙
시즌 코드: `2425` = 2024/25, `2526` = 2025/26, `2627` = 2026/27
국가 코드: `KOR` 한국 / `JPN` 일본 / `USA` MLS / `BRA` 브라질

전체 목록은 `python3 tools/fetch_results.py --list`로 본다.

### 3-2. 받아서 돌리기

```bash
# 유럽 5대 리그, 최근 3시즌
python3 tools/fetch_results.py --div E0 SP1 D1 I1 F1 --seasons 2425 2526 2627 -o results.csv
python3 tools/baserate.py results.csv --by league

# K리그 (파일에 전 시즌이 섞여 있으므로 시즌을 거른다)
python3 tools/fetch_results.py --extra KOR -o kleague.csv
python3 tools/baserate.py kleague.csv --season 2025
```

네트워크가 막혀 있으면 브라우저로 <https://www.football-data.co.uk/data.php>에 들어가
CSV를 직접 내려받아도 결과는 같다. `baserate.py`는 두 포맷을 자동으로 인식한다
(`FTHG/FTAG`와 `HG/AG` 둘 다 읽는다).

### 3-3. 표 갱신

1. 출력값으로 위 표를 덮어쓴다
2. 이 문서 상단의 **마지막 갱신** 날짜를 바꾼다
3. 최소 **직전 2시즌 + 현시즌 누적**을 합쳐 뽑는다. 한 시즌만으로는 표본이 부족하다
   (EPL 한 시즌 380경기는 무승부 비율 추정에 ±2%p 오차가 붙는다)
4. 시즌 개막 직후에는 해당 시즌 파일이 아직 없거나 몇 경기만 들어 있다.
   `--seasons`에 직전 시즌을 반드시 함께 넣는다

### 3-4. xG는 여기서 안 나온다 — 별도 소스가 필요하다

`baserate.py`가 만드는 건 **홈승/무/원정승 비율과 평균 득점**뿐이다.
λ 조립(`확률_산출_규칙.md` 2절)에 필요한 **팀별 90분당 xG For/Against**는 따로 봐야 한다.

| 소스 | 받는 법 | 비고 |
|---|---|---|
| **FBref** | 리그 Squad Standard/Shooting 표 → `Share & Export → Get table as CSV` | 팀별 xG·xGA·90분당 값이 한 표에 있다. 가장 편하다 |
| **Understat** | 리그 페이지의 팀 테이블 | xG 모델이 FBref와 다르다 |

**한 글 안에서 두 소스를 섞지 않는다.** xG 모델이 달라 값이 어긋난다.
어느 쪽을 썼는지 참고사항에 반드시 적는다.

K리그는 FBref·Understat 커버리지가 유럽만큼 좋지 않다.
xG를 못 구하면 정보 등급을 한 단계 내리고(대개 C), 주력 픽을 내지 않는다.

## 4. 참고 — 홈 어드밴티지의 실제 의미

홈 어드밴티지는 "홈팀이 이길 확률"이 아니라 **득점 기대값의 차이**로 다뤄야 한다.
`baserate.py`의 `홈 어드밴티지` 출력이 그 값이다(보통 +0.25 ~ +0.40골).

λ 조립에서 홈/원정 평균을 따로 쓰면 이미 반영된 것이므로, 여기에 다시
"홈이니까 +10%" 같은 조정을 얹으면 **이중 계산**이 된다. 자주 나오는 실수다.
