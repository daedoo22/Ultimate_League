# 확률 산출 규칙 (v2)

이 문서가 모드 A의 확률 계산 방식을 규정한다. 시스템 프롬프트보다 이 문서가 우선한다.

---

## 0. 무엇이 바뀌었나

| | v1 (기존) | v2 (현행) |
|---|---|---|
| 확률의 출처 | 시나리오 A/B/C에 확률 배분 | 기대득점 → 스코어 분포 |
| 시나리오의 역할 | 확률을 **생성** | 이미 나온 확률을 **설명** |
| 마진 제거 | 비례 정규화 | Shin |
| 시장과의 관계 | 시장은 비교 대상 | 시장이 **기준점**, 모델은 이동 폭만 담당 |
| 무승부 | 별도 통제 없음 | 리그 베이스레이트 기준 이탈 상한 |
| 픽 임계치 | 고정 | 정보 등급에 연동 |

**핵심 전환은 하나다.** v1은 이야기를 만든 뒤 거기에 숫자를 붙였다.
사람은 이야기를 만들 때 무승부를 잘 상상하지 못하고, 약팀의 승리를 과대평가하며,
최근 경기 결과에 과도한 가중치를 준다. 그래서 v1의 확률은 체계적으로 틀린다.
v2는 분포를 먼저 계산하고 이야기는 나중에 붙인다.

---

## 1. 계산 순서 (반드시 이 순서)

```
① 시장 공정확률      배당 → Shin 디빅        tools/devig.py
② 기대득점 산출       xG 기반 λ 조립          아래 2절
③ 모델 확률          λ → 스코어 분포          tools/poisson.py
④ 정성 조정          부하·부상·전술 (상한 있음) 아래 4절
⑤ 블렌딩            시장 쪽으로 수축          tools/devig.py edge
⑥ 검산              합·무승부 하한·모순 점검   reference/검증_체크리스트.md
⑦ 시나리오 서술      ⑤의 결과를 이야기로 설명   모드 A 템플릿
```

②~④를 못 하면 ①을 그대로 쓰고 **PASS**로 간다.
"시장확률에 감으로 몇 %p 더한 값"을 모델확률이라고 쓰면 안 된다. 그건 v1과 같다.

## 2. 기대득점(λ) 조립

```
λ_home = 리그평균홈득점 × 홈팀_공격지수 × 원정팀_수비지수 × 조정계수
λ_away = 리그평균원정득점 × 원정팀_공격지수 × 홈팀_수비지수 × 조정계수
```

- **공격지수** = (팀 90분당 xG) / (리그 평균 90분당 xG)
- **수비지수** = (팀 90분당 피xG) / (리그 평균 90분당 피xG)
- 표본은 **최근 10경기 + 시즌 누적**을 6:4로 가중한다. 최근 5경기만 쓰면 노이즈에 끌려간다.
- 시즌 초반 6라운드 이하는 **직전 시즌 값을 50% 섞는다.** 표본이 없으면 리그 평균으로 대체한다.
- 득점(goals)이 아니라 **xG**를 쓴다. 득점은 결정력 변동 때문에 예측력이 낮다.
- 승격팀·감독 교체 직후는 지수를 리그 평균 쪽으로 30% 당긴다.

λ는 각각 **0.4 ~ 3.5** 범위를 벗어나면 계산이 틀린 것이다. 다시 확인한다.

`--rho`는 기본 -0.13을 쓴다. 이 값이 무승부 비중을 현실 수준으로 끌어올린다.
(독립 포아송은 무승부를 3%p가량 과소평가한다 — `poisson.py` 출력에서 직접 확인 가능하다.)

## 3. 마진 제거

`tools/devig.py`를 쓴다. 손으로 계산하지 않는다.

- **기본 방식은 Shin.** 1X2·2-way 모두 동일하게 적용한다.
- 비례 정규화(`p_raw / sum(p_raw)`)는 **더 이상 쓰지 않는다.** 언더독을 과대평가한다.
- 오버라운드가 **7%를 넘는 배당판은 기준으로 삼지 않는다.** 마진이 클수록
  디빅 오차가 커져 엣지 계산이 무의미해진다. 저마진 북(오버라운드 103~105%)을 기준으로 쓰고,
  실제 거래하는 판은 따로 표기한다.
- 배당이 한쪽만 있으면 시장확률 표기를 생략하고, 그 마켓은 픽 대상에서 제외한다.

### 아시안 핸디 쿼터 라인
`-0.75 = -0.5 절반 + -1.0 절반`. `poisson.py --ah`가 자동 처리한다.
정푼 라인의 푸시 확률은 **2% 이상이면 반드시 표기**한다(축구 정푼 라인은 대부분 2%를 넘는다).
2-way 확률 비교는 **푸시를 제외한 커버 확률**(`win / (win + lose)`)로 한다.

## 4. 정성 조정 — 상한이 있다

부상·체력 부하·전술 매치업은 **λ를 통해서만** 반영한다. 확률을 직접 손대지 않는다.

| 요인 | λ 조정 폭 | 조건 |
|---|---|---|
| 핵심 공격수 결장 (팀 xG 기여 20%+) | -0.15 ~ -0.30 | 결장 **확정**된 경우만 |
| 주전 GK·센터백 결장 | 상대 λ +0.10 ~ +0.20 | 확정된 경우만 |
| 3일 간격 2연속 풀타임 다수 | -0.10 ~ -0.15 | 핵심 5명 이상 해당 시 |
| 미드위크 유럽대항전 원정 직후 | -0.10 ~ -0.20 | 이동거리 1000km 이상 |
| 대륙 간 A매치 차출 복귀 | -0.05 ~ -0.15 | 복귀 후 첫 경기 |
| 강풍·폭우 | 양팀 각 -0.10 ~ -0.20 | 예보 확인된 경우 |
| 동기 격차 (강등 사투 vs 소화경기) | ±0.10 | 근거 명시 필수 |

**합산 상한: 한 팀당 λ 조정 총량 ±0.45.** 이걸 넘으면 정성 판단이 모델을 삼킨 것이다.

**하지 않는 조정**
- "홈 분위기가 좋다", "기세를 탔다", "감독의 승부수" 같은 서술은 λ를 건드리지 않는다.
- 상대전적(H2H)은 조정 근거로 쓰지 않는다. 표본이 10경기 이하고 선수 구성이 달라졌다.
  본문 서술 소재로만 쓴다.
- 최근 3경기 결과 자체로 조정하지 않는다. xG에 이미 반영돼 있다.

## 5. 블렌딩 — 시장 가중치는 정보 등급에 연동

```
p_final = w × p_market + (1 - w) × p_model     (이후 이탈 상한으로 클리핑)
```

| 정보 등급 | 조건 | w (시장가중치) | 이탈 상한 |
|---|---|---|---|
| **A** | 공식 라인업 발표 후 + 양팀 xG 표본 10경기 이상 | 0.65 | 8%p |
| **B** | 예상 라인업 + 부상 확정 + xG 표본 충분 | 0.78 | 6%p |
| **C** | 예상 라인업 불확실 또는 로테이션 변수 큼 | 0.88 | 4%p |
| **D** | 시즌 6R 이하 / 컵대회 / 승격팀 / 감독 교체 직후 | 0.95 | 2%p |

D등급은 사실상 시장을 그대로 쓴다는 뜻이다. **D등급은 무조건 PASS다.**

> 왜 이렇게까지 시장에 기대는가.
> 클로징 라인은 공개 정보 기준으로 가장 강한 단일 예측자다.
> 텍스트 분석이 그것을 통째로 이길 가능성은 낮다.
> 시장을 기준점으로 두면 최악의 오류(확률을 30%p씩 틀리는 것)가 구조적으로 차단되고,
> 그것만으로 Brier score가 크게 개선된다.
> 자유도를 줄이는 것이 정확도를 올리는 가장 확실한 방법이다.

## 6. 검산 (출력 직전, 예외 없음)

- [ ] 홈승 + 무 + 원정승 = 100.0% (±0.1%p)
- [ ] 2-way 합 = 100.0%
- [ ] **무승부 확률이 리그 베이스레이트 대비 ±6%p 이내인가.**
      벗어나려면 명시적 근거(양팀 극단적 저득점 지표 등)를 본문에 적는다.
- [ ] 무승부가 18% 미만이거나 34% 초과인가 → 거의 확실히 계산 오류다. 재검산.
- [ ] p_final이 시장 대비 이탈 상한 안에 있는가
- [ ] λ가 0.4~3.5 범위인가
- [ ] 본문 서술 방향과 최종 확률이 같은 쪽을 가리키는가

## 7. 픽 임계치 (v2 — 상향)

블렌딩 **이후** 확률 기준이다. 블렌딩 전 모델확률로 판정하면 안 된다.

| 마켓 | 주력 | 부주력 | 그 외 |
|---|---|---|---|
| 1X2 단일 | p ≥ 52% **AND** 엣지 ≥ 4.0%p | p ≥ 45% AND 엣지 ≥ 2.5%p | PASS |
| 더블찬스·AH·U/O (2-way) | p ≥ 58% **AND** 엣지 ≥ 3.0%p | p ≥ 54% AND 엣지 ≥ 2.0%p | PASS |

**주력 픽 금지 조건 (하나라도 걸리면 부주력 이하)**
1. 정보 등급 C 또는 D
2. 공식 라인업 미발표 상태에서 핵심 선수 출전 여부가 불확실
3. 미드위크 유럽대항전 직후 또는 순위 확정된 최종 라운드
4. 오버라운드 7% 초과 배당판만 확보된 경우
5. 같은 날 이미 주력 픽을 1개 냈을 때 (하루 주력 1개)

**주력은 경기당 1개, 하루 1개.** 나머지는 부주력 또는 PASS다.
파생 마켓(코너·카드·선수 득점)은 주력 대상이 아니다.

> v1의 "1X2 55% + 엣지 4%p"는 실은 통과가 거의 불가능한 조건이었고,
> 그래서 실제로는 조건을 무시한 픽이 나갔다. v2는 확률 하한을 현실적으로 낮추는 대신
> **엣지 계산을 엄격하게** 만들었다. 블렌딩을 거치면 엣지 4%p는 모델이 시장과
> 10%p 이상 갈렸다는 뜻이라 충분히 강한 신호다.

## 8. 기록 의무

PASS도 기록해야 "냈으면 맞았을 것"을 사후에 미화하지 않는다.

킥오프 직전 배당(`closing_odds`)은 반드시 채운다.
표본 30건 이하 구간에서 판단의 옳고 그름을 알려주는 지표는 **CLV뿐**이다.

20건 쌓일 때마다 실행한다.

python3 tools/calibrate.py logs/picks.csv --split
